## Scope

This run validates the v0.2 Handoff architecture and the State lifecycle interface while keeping the evidence boundary explicit: the first two upstream Handoffs were exercised through real user invocations; the remaining Gate transitions were exercised by isolated deterministic fixtures.

### Decision Handoff

1. Project Preflight printed an exact `$wayfinder` invocation plus the explicit return to `$project-preflight`.
2. The user explicitly invoked `$wayfinder`.
3. Wayfinder created a canonical local-Markdown map, eight decision tickets, blocking relationships, and a primary-source model-API research result without modifying Preflight state.

5. Project Preflight recorded the map pointer, correctly kept the project at `DECISION`, and blocked Gate 2 because the decision tickets were still open.

This proves the user-visible stop-and-resume boundary and the rule that an upstream artifact does not automatically pass a Gate.
