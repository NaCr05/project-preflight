# Code of Conduct

## Our standard

Project Preflight welcomes constructive participation. Be respectful, assume good faith, focus criticism on ideas and observable behavior, and protect private project information. Harassment, discrimination, threats, sexualized attention, deliberate disruption, and publishing another person's private information are not acceptable.

## Scope

This standard applies in repository issues, pull requests, reviews, discussions, and other public spaces used to represent the project.

## Reporting and enforcement

For a non-sensitive concern, open an issue that describes the behavior without reposting private or harmful material. For a sensitive concern, contact the maintainer through a private contact method listed on the [NaCr05 GitHub profile](https://github.com/NaCr05). Do not use the vulnerability-reporting channel unless the report is also a security vulnerability.

The maintainer may edit or remove contributions, warnings, comments, or access when necessary to protect participants and the project. Enforcement decisions should consider context, severity, repetition, and whether harm was repaired. Reports will be handled as privately as the available channel permits, but no response-time guarantee is made.
